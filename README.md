This project corresponds to User Story M1S3 – Modular Inventory Management System with CRUD Operations and CSV Persistence and was developed in Python to create a complete inventory management application using modular programming principles. The system is divided into three modules: app.py, which contains the user interface and menu-driven workflow; servicios.py, which manages all inventory operations such as creating, reading, updating, deleting, searching products, and generating statistics; and archivos.py, which handles data persistence through CSV file import and export. Products are stored as dictionaries containing a name, price, and quantity, while the inventory itself is maintained as a list of products. The application provides a full CRUD implementation, allowing users to add new products, display the inventory, search products by name, update existing records, and remove products from the system. Additionally, it calculates useful inventory statistics, including total units, total inventory value, the most expensive product, and the product with the highest stock level. The program incorporates robust error handling through try/except blocks to validate user input and prevent application crashes caused by invalid data. CSV functionality enables users to save inventory data to external files and reload it later, including validation of file structure, data types, and negative values, while reporting invalid rows when necessary. The menu-driven interface continuously runs until the user chooses to exit, providing a user-friendly experience and demonstrating key software engineering concepts such as modular architecture, separation of concerns, reusable functions, data persistence, exception handling, CRUD operations, list and dictionary manipulation, and inventory analytics. This implementation represents a significant progression from previous user stories by introducing file management, modular design, and scalable inventory management capabilities suitable for real-world applications.
